# SQL Data Cleaning using PostgreSQL

## 📌 HANDS-ON-PRACTICE Overview

This project(HANDS-ON-PRACTICE) focuses on practical data cleaning techniques using **PostgreSQL**. The goal is to identify data quality issues, improve data consistency, and prepare raw employee data for further analysis.

I worked with an employee dataset and performed different SQL operations to identify and handle common data quality problems.

## 🛠️ Tools & Technologies
- PostgreSQL
- SQL
- pgAdmin / SQL Editor

## 📊 Data Cleaning Tasks

1. **Data Inspection** – Explored the dataset and checked column names and data types.
2. **Missing Values** – Identified NULL and blank values.
3. **Text Cleaning** – Removed unwanted leading and trailing spaces using `TRIM()`.
4. **Duplicate Records** – Identified duplicate records using `ROW_NUMBER()`.
5. **Age Validation** – Checked invalid and inconsistent age values.
6. **Salary Validation** – Identified invalid salary values.
7. **Date Validation** – Checked missing and potentially invalid hire dates.
8. **Date Formatting** – Displayed dates in `DD/MM/YY` format using `TO_CHAR()`.
9. **Data Type Conversion** – Practiced converting columns into appropriate data types.

## 🎯 Key Learnings

- Improved understanding of SQL data cleaning techniques.
- Learned how to identify common data quality issues.
- Practiced using SQL functions, conditions, CTEs, and window functions.
- Understood the importance of data quality before analysis.
